# 🗺️ U.S. States Guessing Game

An interactive geography game built with Python's `turtle` graphics library and the `pandas` library. Test your knowledge of all 50 U.S. states by guessing their names and seeing them appear in their correct locations on the map.

---

## 📖 Overview

The U.S. States Guessing Game is an educational project that combines Python programming with geography. Players are presented with a blank map of the United States and are prompted to enter the names of U.S. states. Whenever a correct state is entered, its name is displayed at the appropriate location on the map.

The game continues until all 50 states have been guessed or the player chooses to exit. If the player exits before completing the game, the program automatically generates a **states_to_learn.csv** file containing the names of all states that were not guessed, making it a useful learning tool for future practice.

The project demonstrates how to integrate graphical interfaces with external datasets while following a clean and modular programming approach.
